## About

I research wireless protocol stacks and build the systems that run them. My work focuses on three connected areas — **WLAN (IEEE 802.11)**, **cellular (3GPP LTE/5G NR)**, and **AI for wireless** — with a common thread: scheduling under constraints, or how different layers decide what runs where, when, under fixed latency and power budgets.

---

## Focus Areas

### WLAN — IEEE 802.11
- Studied MAC/PHY operation across **802.11n/ac/ax**: CSMA/CA, DCF/EDCA, A-MSDU/A-MPDU aggregation, block acknowledgment, OFDMA, MIMO, channel bonding, and rate adaptation.
- Investigated coexistence and performance degradation in dense and IoT scenarios using packet-level analysis (**Wireshark**) and simulation (**ns-3**).
- Tracking **Wi-Fi 7/8** developments (802.11be/bn): multi-link operation, UHR, and power-saving mechanisms.

### Cellular — 3GPP LTE / 5G NR
- Studied RAN and core protocol architecture across **RRC, NAS, PDCP, RLC, MAC, and PHY**, including random access, HARQ, scheduling, mobility management, and QoS flow/bearer mapping.
- Analyzed NR Layer 2 behavior and the evolution toward **5G-Advanced/6G** (RedCap, eRedCap, NTN).
- Familiar with 3GPP specification structure (**TS/TR**), release tracking, and procedure-level analysis.

### AI for Wireless
- Current research: **AI-based interference detection and suppression** in WLAN and cellular systems.
- Applied ML/DL to **link adaptation** and **intelligent scheduling**, with simulation and SDR-oriented validation.
- Exploring how AI agents and LLM inference engines share the same scheduling constraints as RAN MAC schedulers — determinism, memory semantics, and interface semantics.
